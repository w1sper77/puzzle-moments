# 拼图片刻 · 移动端 H5 可玩版

依据《拼图片刻》GDD V1.0 实现的 P0 可玩原型。竖屏、单指触控、离线可玩、本地保存进度。

## 运行

### 方式一：直接打开

双击 `index.html` 即可在浏览器游玩。

### 方式二：本地静态服务

```bash
cd outputs/puzzle-moments
python3 -m http.server 8080
```

打开 `http://localhost:8080`。

建议使用浏览器开发者工具切换到 iPhone / Android 竖屏尺寸，或在手机浏览器打开。

## 已实现范围

- 经典切块：3×3 / 4×4 / 5×5，底部托盘、拖拽吸附、正确锁定、错误弹回、0.35 格容差。
- 滑块华容道：3×3 / 4×4，随机合法移动打乱，天然可解；点按/轻扫、150ms 补间、连点缓冲。
- 计时、步数、完整度、提示 3 次、星级、分数、时间奖励与提示扣减。
- 解锁链：主题包 A/B 共 12 张内置 SVG 关卡图；经典 4×4/5×5、滑块模式与滑块 4×4 解锁。
- 暂停遮罩、切后台自动暂停、退出续局快照、首页继续上局、最佳成绩。
- 经典/滑块新手引导、音效、震动、粒子开关、底图开关、竖屏提示。
- 本地埋点记录与 `window.PuzzleAnalyticsHooks.send` 上报接口预留。
- 引擎回归：`engine.js` 可在 Node 中复算 GDD 表 1 的 6 组分数样例。

## 目录

- `index.html`：页面骨架。
- `styles.css`：移动端 UI、动画与触控反馈。
- `assets.js`：12 张离线内嵌 SVG 关卡图。
- `engine.js`：纯规则引擎：难度配置、打乱、计分、本地存储。
- `app.js`：界面、状态机、拖拽/滑动、引导、存档与埋点。
